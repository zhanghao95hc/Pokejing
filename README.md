# 雾岬物语 · 山海设色版

Levi 从雾岬研究站出发，沿海岸收集两枚徽章。两片区域共有八个地点、十二个图鉴条目和一场可重复参加的双打交流赛。

## 启动与旧存档

解压整个目录，在 Chrome 或 Edge 中打开 `index.html` 即可离线游玩。使用网页入口时，刷新同一地址即可加载新版。存档保存在当前浏览器与入口下。旧版进度随首次读取自动升级，原始存档会留一份本地备份。旧伙伴保留个体值和能力，采用中性性格，努力值从零开始。旧档中的单打或双打可接着当前回合继续。

右上角「菜单」或 M 打开冒险菜单。队伍、地点、行囊、灵兽谱和手记都可在这里查看。「设置」可切换探索视角、音乐和音效，支持全屏的浏览器还可进入全屏显示。

## 调查路线

海岸的短草地和盐镜湾的干沙滩可以自由穿行。五片高草和四片芦荡里有野生灵兽，每走一格都有机会遇见。沿平地可绕过它们。潮声浅滩靠海的一片芦荡还可以垂钓。

1. 从筠角鹿、朱砂狐、荷灯鲤中选一位出发。默认推荐筠角鹿。
2. 在风铃草甸削弱野生伙伴后投出结缘铃。红绳收拢后，铃会按当次判定摇响，三响后红绳结成同心结。挣脱时绳结散开，野生伙伴回到场上。结缘概率随目标体力和异常状态变化。研究站免费恢复体力与招式次数，补足基础物资。
3. 到林间练习场击败青禾，再登上望潮灯台挑战岑川，获得潮光徽章。
4. 获得潮光徽章后，在雾岬研究站或望潮灯台旁按 E（或点「调查」），从建筑菜单选择「搭船去盐镜湾」。调查潮汐小屋并选择「拜访渔舍」可领取潮线竿。浅滩既可调查潮草，也可抛竿等浮标下沉后提竿。调查盐镜渡口并选择「返回雾岬」可乘船返航。
5. 结缘瓦当蟹、桂月蛾、潮钟螺中的任意一只，挑战盐镜观测台的汐弦。她依次派出三位双属性伙伴，获胜后授予镜潮徽章。
6. 从盐镜渡口返航可继续补全图鉴、培养伙伴。持第一枚徽章并携带至少两位有体力的伙伴，可在望潮灯台参加双打交流赛。

## 对战与培养

27 个招式各有一套四帧国风插画特效。单打和双打依实际速度、先制和目标播放，可点「略过招式」直接查看回合结果。三只初始灵兽升至九级时会经历三个过渡形态。进化中刷新可以续看，在已进化伙伴的「队伍 → 详情」中可选择「重看进化」。

- **培养**　每只伙伴拥有六项个体值、六项努力值和一种性格。新伙伴的个体值在 0～31 间生成，25 种性格分别影响能力成长。参战并存活的伙伴在击倒对手后累积对应努力值，每项上限 255，总量上限 510。队伍详情可查看具体数值。
- **属性**　七种属性参与计算。双属性分别结算，例如草木招式对岩石与水栖的瓦当蟹为四倍。普通、岩石、风羽攻击使用攻击与防御，草木、火焰、水栖、雷电攻击使用特攻与特防。同系加成、先制、速度、要害、命中和伤害浮动进入回合结算。
- **天气与特性**　烈日增强火焰、削弱水栖，降雨效果相反。技能天气持续五个回合，单打和双打共用规则。潮钟螺在雨天速度翻倍，雷纹貉可吸收雷电招式，负砚龟的层甲可以挡下要害。三位初始伙伴体力偏低时增强本系威力。
- **状态**　灼伤和中毒在回合末扣除体力。灼伤降低物理输出，麻痹降低速度且可能打断行动。睡眠持续一至三次行动。可使用清醒露、携带净芽果或前往补给点解除异常。
- **整备**　在研究站或潮汐小屋打开「队伍 → 详情 → 整备招式」。每位最多携带四招，栏位满时可以指定替换。Lv.7 解锁第四个物种招式，三只初始伙伴在 Lv.9 进化。新招式包括改变天气的引潮歌和拨云调，以及先制防护的回岬护幕。连续使用护幕会降低成功率。
- **装备与补给**　胜利获得潮币。研究站和潮汐小屋的商店出售六种道具。在伙伴详情更换携带物。露心果在半血时自动回血，净芽果自动解异常，潮纹镜强化本系伤害。前两种果实触发后消耗。
- **双打**　分别选择两位场上伙伴的指令和目标。可以换人、用药，或让一位开护幕、另一位进攻。「叠浪」同时攻击两名对手，双目标时每名承受 75% 伤害。一名伙伴倒下时，后备队员依次接替。
- **队伍**　最多携带六位伙伴。满队时，新伙伴在研究站寄养，可以回研究站交换队员。等级上限为 50。

## 操作

| 场景 | 操作 |
| --- | --- |
| 选择伙伴 | 点击卡片或按 A / D 切换，Enter 出发 |
| 探索 | WASD 或方向键点按走一格，按住连续移动，E 调查。点陆地或在「菜单 → 沿途地点」选择目的地自动寻路，在两处平地之间优先绕开高草。默认跟随 Levi，可在「设置」切换广角 |
| 菜单 | M 打开或关闭，Esc 返回上一级。沿途地点的航图和清单都能选取目的地 |
| 单打 | 点击招式或按 1～4，屏幕显示克制倍率和剩余 PP |
| 双打 | 在两个指令栏中选择招式、道具或替补，再执行回合 |
| 移动端 | 按住屏幕方向键连续走，松手停下。也可点地图或地点列表前往 |
| 存档 | 每步移动与每回合自动保存。行囊提供带确认的重开选项 |

## 版本与素材

这是原创单机游戏的第二个可玩版本，使用独立的地区、怪物、数值与关卡。当前包含两枚徽章、七种属性、四种持续异常状态。繁育、联机交换、多人对战与完整长篇联盟战役尚未实现。

两地航图、山海长卷、战斗场地、十二种灵兽的正背面、Levi 四向行走和六种道具均使用原创工笔重彩插画，灵兽用藏青外轮廓收边，竹林草地与盐镜湾潮滩的山石、古建集中在远景。游戏素材位于 `assets/color/`。旧版存档继续使用原来的物种标识、等级、个体值、招式、道具和战斗回合，读取冒险记录时会显示新的灵兽名称。旧位置仍可通行时原地接续，地形变动时从最近的可行走地面接续。探索与战斗配乐位于 `assets/field/`。

## 开发验证

在游戏目录下运行 `node --test tests/*.test.cjs` 可验证成长、存档迁移、两地寻路、天气、道具、捕捉、单打和双打。游玩无需 Node.js。

| 初始伙伴 | 九级进化 | 造型 |

| 筠角鹿 | 松烟麟 | 竹笋角与露斑长成松角、青鳞和烟尾 |
| 朱砂狐 | 丹霞三尾 | 一点朱砂尾火长成三缕丹霞 |
| 荷灯鲤 | 踏浪螭 | 荷瓣鱼鳍与鲤须化入无角水螭的身形 |
