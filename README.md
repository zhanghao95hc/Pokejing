# 雾岬物语 · 山海设色版

Levi 从雾岬研究站出发，为夜船修引灯、替盐船找航道，赢得两枚徽章。两章各有五片区域、二十五个调查地点和路口。沿岸可收集十五支灵兽谱系的四十五种形态，望潮灯台可重复参加双打交流赛。「灵兽谱 → 远域卷」另收录五十支后续地图谱系。

## 启动与旧存档

解压整个目录，在 Chrome 或 Edge 中打开 `index.html` 即可离线游玩。使用网页入口时，刷新同一地址即可加载新版。存档保存在当前浏览器与入口下。旧版进度随首次读取自动升级，原始存档会留一份本地备份。已获徽章和航线继续有效，也可重访新地图补做调查。旧伙伴保留个体值和能力，采用中性性格，努力值从零开始。旧档中的单打或双打可接着当前回合继续。

右上角「菜单」或 M 打开冒险菜单。队伍、地点、行囊、灵兽谱和手记都可在这里查看。「设置」可切换探索视角、音乐和音效，支持全屏的浏览器还可进入全屏显示。

## 调查路线

海岸的短草地和盐镜湾的干沙滩可以自由穿行。五片高草和四片芦荡里有野生灵兽，每走一格都有机会遇见。沿平地可绕过它们。潮声浅滩靠海的一片芦荡还可以垂钓。

1. 从筠角鹿、朱砂狐、荷灯鲤中选一位出发。默认推荐筠角鹿。
2. 在风铃草甸削弱野生伙伴后投出结缘铃。红绳收拢后，铃会按当次判定摇响，三响后红绳结成同心结。挣脱时绳结散开，野生伙伴回到场上。结缘概率随目标体力和异常状态变化。研究站免费恢复体力与招式次数，补足基础物资。
3. **第一章 · 风从哪边来**　在研究站按 E，步行进灯匠镇，到灯纸作坊向桑婆接下灯匣。从竹门巷出镇，沿竹影驿道查看送灯驿亭的旧签。驿道北面的丹砂古窑留着两种灯片，东面通栖风岭。回海岸与练习场的青禾切磋，即可从驿道或练习场上岭。听风竹架给出灯窗方向；带着找回的灯片去石龛引灯，再回望潮灯台挑战岑川。
4. 获得潮光徽章后，在雾岬研究站或望潮灯台的建筑菜单选择「搭船去盐镜湾」。调查潮汐小屋领取潮线竿，在潮声浅滩等浮标下沉后提竿。盐镜渡口的菜单同时提供返航与进港两条路线。
5. **第二章 · 潮退三声**　从盐镜渡口步行进盐栈港，向盐运船行借索。从港东上潮田长堤，在验潮工棚查巡堤簿，再从石门进入洄声石窟，凭回声打捞钟舌。沿长堤东行进入鸣沙泽，在双柱潮尺拓下钟谱，到回澜钟架敲出退潮信号。敲到一半可以存档。沿芦汀旧埠回潮汐小屋，带着本地灵兽结缘记录去观测台挑战汐弦。
6. 从盐镜渡口返航可继续补全图鉴、培养伙伴。持第一枚徽章并携带至少两位有体力的伙伴，可在望潮灯台参加双打交流赛。

两张野外道路各采用 90 × 60 的步行网格。竹影驿道有五片高草，潮田长堤有四片芦草，两条路都可以绕开草丛走到出口。沿途可挑战驿骑阿栩、巡堤人阿苇，也可搜集一次性行囊。两个城镇都有免费客房和使用潮币的商铺。古窑和石窟各有线索与补给。

路口标牌标着下一站。走到标牌处即可换区，也可在附近按 E 选择步行。研究站和盐镜渡口保留建筑菜单。「菜单 → 沿途地点」可以打开本章行旅图，在当前地图点选地点后，Levi 会实际步行过去。已开始旧版山岭或湿地调查的存档，可以继续原来的灯窗或钟谱进度。

十片区域里有十六位带着灵兽的旅人。研究站东侧可以遇见投书人阿缃和衔枝雀，盐镜渡口东边有桂姨和白额潮獭。走到旅人或伙伴旁边按 E，或直接点选人物、灵兽，Levi 会走到可落脚的相邻位置交谈。对话时可按 E、Enter 或 Esc 返回地图。快跑同样适用于点地寻路，草丛按实际经过的步数判定遇敌。

## 对战与培养

草丛遭遇以枝叶掠过画面开场，水边与垂钓改用潮浪，挑战旅人和双打各有一幅旗阵。画面合拢后，对手剪影先滑入场，我方伙伴随后登场。点击「略过入场」或按空格、Enter、Esc 可以跳过。已保存的战斗从当前回合继续。

七种属性共有 75 种可习招式，另有 PP 耗尽时的「奋力撞击」，使用 27 套四帧国风插画特效。单打和双打依实际速度、先制和目标播放，可点「略过招式」直接查看回合结果。沿岸的十五支谱系均有初阶、中阶和终阶。经验跨过多个门槛时，会依次登记每个形态并播放两段演出。演出中刷新可以续看，终阶伙伴的「队伍 → 详情」可分别重看两次进化。旧存档中已经达到门槛的伙伴可在详情中点「现在进化」，或在下次获得经验时自动进化，满级伙伴同样适用。

- **培养**　每只伙伴拥有六项个体值、六项努力值和一种性格。新伙伴的个体值在 0～31 间生成，25 种性格分别影响能力成长。参战并存活的伙伴在击倒对手后累积对应努力值，每项上限 255，总量上限 510。队伍详情可查看具体数值。
- **属性**　七种属性参与计算。双属性分别结算，例如草木招式对岩石与水栖的瓦当蟹为四倍。每个攻击招式单独标注物理或特殊。例如同为水栖的「浪钩」使用攻击和防御，「穿珠流」使用特攻和特防。同系加成、先制、速度、要害、命中和伤害浮动进入回合结算。
- **天气与特性**　烈日增强火焰、削弱水栖，降雨效果相反。技能天气持续五个回合，单打和双打共用规则。潮钟螺在雨天速度翻倍，雷纹貉可吸收雷电招式，负砚龟的层甲可以挡下要害。三位初始伙伴体力偏低时增强本系威力。
- **状态**　灼伤和中毒在回合末扣除体力。灼伤降低物理输出，麻痹降低速度且可能打断行动。睡眠持续一至三次行动。可使用清醒露、携带净芽果或前往补给点解除异常。
- **整备**　随时可在「队伍 → 详情 → 查看招式谱」核对当前形态的等级、进化、师授、秘卷、同伴和回忆条目；在研究站、潮汐小屋或城镇客栈可选招换装。每只可装备四招。升级或进化时有空位直接学会，满栏则在离开战斗后选择替换，也可以保留原招。潮光与镜潮徽章分别开放一层可重复使用的秘卷；同伴传习要求队伍中已有伙伴装备兼容招式。换下的招式保留回忆记录。
- **谱系招式**　成长表延伸至 Lv.50。属性决定基础路线，战斗定位补充支援或攻击招式，每支谱系另有两种家传技，可在 Lv.18、Lv.34 或更早的自然节点领悟。例如负砚龟能学「露脉点穴」，潮钟螺能学「玉磬音」。双击每段分别判定命中，只扣一次 PP。天气、异常状态、体力高低和防守等级都会改变对应招式的表现。
- **装备与补给**　胜利获得潮币。研究站和潮汐小屋的商店出售六种道具。在伙伴详情更换携带物。露心果在半血时自动回血，净芽果自动解异常，潮纹镜强化本系伤害。前两种果实触发后消耗。
- **双打**　分别选择两位场上伙伴的指令和目标。可以换人、用药，或让一位开护幕、另一位进攻。「叠浪」同时攻击两名对手，双目标时每名承受 75% 伤害。一名伙伴倒下时，后备队员依次接替。
- **队伍**　最多携带六位伙伴。满队时，新伙伴在研究站寄养，可以回研究站交换队员。等级上限为 50。

## 操作

| 场景 | 操作 |
| --- | --- |
| 选择伙伴 | 点击卡片或按 A / D 切换，Enter 出发 |
| 探索 | WASD 或方向键点按走一格，按住连续移动。按住 Shift 以两倍速度跑动，松开恢复步速。E 调查或交谈。点陆地或在「菜单 → 沿途地点」选择目的地自动寻路，在两处平地之间优先绕开高草。默认跟随 Levi，可在「设置」切换广角 |
| 菜单 | M 打开或关闭，Esc 返回上一级。沿途地点的航图和清单都能选取目的地 |
| 单打 | 点击招式或按 1～4，屏幕显示克制倍率和剩余 PP |
| 双打 | 在两个指令栏中选择招式、道具或替补，再执行回合 |
| 移动端 | 按住屏幕方向键连续走，松手停下。也可点地图或地点列表前往 |
| 存档 | 每步移动与每回合自动保存。行囊提供带确认的重开选项 |

## 版本与素材

这是原创单机游戏的山海调查篇，使用独立的地区、怪物、数值与关卡。当前包含两枚徽章、七种属性、四种持续异常状态。繁育、联机交换、多人对战与完整长篇联盟战役尚未实现。

两章航图、山海长卷、战斗场地、一百二十五种形态的正背面、Levi 四向行走和六种道具均使用原创工笔重彩插画，灵兽用藏青外轮廓收边，竹林草地与盐镜湾潮滩的山石、古建集中在远景。游戏素材位于 `assets/color/`。旧版存档继续使用原来的物种标识、等级、个体值、招式、道具和战斗回合，读取冒险记录时会显示新的灵兽名称。旧位置仍可通行时原地接续，地形变动时从最近的可行走地面接续。探索与战斗配乐位于 `assets/field/`。
